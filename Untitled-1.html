Pythonデモ：Driveで「作る → 見る → わさわさリネーム」

マリちゃん監修・トラちゃん解説。Colabで各自のコピーを実行して体験しよう。

使い方：「Open in Colab」を押すと、見本ノートのコピーがあなたのGoogleドライブに作られます。
あとはセルを上から順に実行してね（各自の環境で動くので、同時実行しても衝突しません）。

① ドライブをマウント

Google ColabにGoogleドライブをつなげます。これでプログラムからドライブへアクセス可能になります。 
from google.colab import drive
drive.mount('/content/drive')
セルを実行 認証→許可

② フォルダを作成（空でスタート）

教材用フォルダ python_demo を作成します。実行が終わったら、左のファイルブラウザで MyDrive/python_demo を開いてください。この時点では中身は空です。 
import os
folder = "/content/drive/MyDrive/python_demo"
os.makedirs(folder, exist_ok=True)
フォルダ作成 左のブラウザで目視確認

③ トラちゃんファイルを5つ作成

torachan_1.txt 〜 torachan_5.txt を作成します。実行後、python_demo フォルダを 開きっぱなしにして、5つのファイルが並んだことを目で確認しましょう。 
paths = []
for i in range(1, 6):
    filename = f"torachan_{i}.txt"
    path = os.path.join(folder, filename)
    with open(path, "w", encoding="utf-8") as f:
        f.write(f"トラちゃんファイル {i}\n")
    paths.append(path)
5ファイル作成 開きっぱなしで確認

④ まとめてリネーム（変化を見る）

作成した5ファイルを、torachan_new_01.txt のように一括リネームします。 フォルダを開きっぱなしにしておくと、名前が一斉に変わるのがわかります。 
import os
for i, old_path in enumerate(paths, start=1):
    new_name = f"torachan_new_{i:02d}.txt"
    new_path = os.path.join(folder, new_name)
    os.rename(old_path, new_path)
    print(f"{os.path.basename(old_path)} → {new_name}")
一括変更 目で変化を確認

（任意）付録：片付け

実習後に片付けたい場合は、以下でフォルダごと削除できます（十分ご注意を）。 
import shutil
shutil.rmtree(folder)  # ※ 実行すると python_demo が丸ごと消えます
