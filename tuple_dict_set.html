辞書の基本

辞書の定型

変数名 = {キー1: 値1, キー2: 値2, ...}

辞書の特徴

  • 辞書は、キーと値のペアを複数まとめて管理するデータ型です。
  • Python 3.7以降の辞書は、要素を追加した順序（挿入順）を保持します。キーの大小などで自動的に並ぶわけではありません。
  • 同じキーに複数の値は保持できません。同じキーを再指定すると、後の値で上書きされます。
  • キーには文字列や数値などのハッシュ可能な値を使います。リストや辞書はキーにできません。

辞書の例

person = {'name': '大久保', 'age': 40, 'gender': '女性'}
print(person)  # 辞書の中身を表示
#結果
{'name': '大久保', 'age': 40, 'gender': '女性'}

辞書の要素を取り出す方法

student = {
51020014:"斎藤勇",
51020777:"福島彩加",
51020687:"吉田雪乃",
51020349:"高橋雅子", 
51020347:"金子久美子"
}

# key だけを取り出す
for key in student.keys():
    print(key)
print()
# value だけを取り出す
for value in student.values():
    print(value)
print()
# キーと値のペアを items() で取り出す
for key, value in student.items():
    print(key, value + 'さん')

タプルの基本

タプルの定型

変数名 = (要素0, 要素1, 要素2, ...)
#（要素が1つだけの場合は最後にカンマが必要：(100,)）

タプルの特徴

  • タプルは、リストと同じように、複数の要素をまとめて管理するデータ型です。
  • タプルは、作成後に要素を追加・削除・置き換えできません。
  • タプルは、丸括弧 ( ) で囲んで表現します。

タプルの例

eto = ('子', '丑', '寅', '卯', '辰', '巳', '午', '未', '申', '酉', '戌', '亥')
print(eto)  # タプルの中身を表示
#結果
('子', '丑', '寅', '卯', '辰', '巳', '午', '未', '申', '酉', '戌', '亥')

weekdays = ('Sunday', 'Monday', 'Tuesday', 'Wednesday', 'Thursday','Friday', 'Saturday')
print(weekdays)  # タプルの中身を表示
#結果
('Sunday', 'Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday')

タプルの要素を取り出す方法

タプルは順序を持ち、添字を使って要素を取り出せます。添字は0から始まります。[-1] は最後の要素を表し、len() は要素の数を返します。

colors = ('赤', '青', '黄')
print(colors[0])   # 赤（最初の要素）
print(colors[-1])  # 黄（最後の要素）
print(len(colors)) # 3（要素の数）

セットの基本

セットの定型

変数名 = {要素1, 要素2, ...}

セットの特徴

  • セットは、重複しない要素をまとめて管理するデータ型です。
  • セットは、集合演算を行うためのデータ型です。
  • 要素の表示順は保証されません。
  • 空のセットは set() で作ります。{} は空の辞書です。

セットの例

fruits = {'apple', 'banana', 'cherry'}
print(fruits)  # セットの中身を表示
#出力例（要素の表示順は異なる場合があります）
{'cherry', 'apple', 'banana'}
#セットに順序という概念はない

セットの集合演算の例

set1 = {1, 2, 3, 4, 5}
set2 = {3, 4, 5, 6, 7}

print(set1 | set2)  # 和集合
#結果
{1, 2, 3, 4, 5, 6, 7}

print(set1 & set2)  # 積集合
#結果
{3, 4, 5}

print(set1 - set2)  # 差集合
#結果
{1, 2}
