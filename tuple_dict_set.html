タプルの基本

タプルの定型

変数名 = (要素0, 要素1, 要素2, ...)

タプルの特徴

  • タプルは、リストと同じように、複数の要素をまとめて管理するデータ型です。
  • リストとの違いは、タプルは要素の追加や削除ができないことです。
  • タプルは、丸括弧 ( ) で囲んで表現します。

タプルの例

eto = ('子', '丑', '寅', '卯', '辰', '巳', '午', '未', '申', '酉', '戌', '亥')
print(eto)  # タプルの中身を表示
#結果
('子', '丑', '寅', '卯', '辰', '巳', '午', '未', '申', '酉', '戌', '亥')

weekdays = ('Sunday', 'Monday', 'Tuesday', 'Wednesday', 'Thursday','Friday', 'Saturday')
print(weekdays)  # タプルの中身を表示
#結果
('Sunday', 'Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday')

辞書の基本

辞書の定型

変数名 = {キー1: 値1, キー2: 値2, ...}

辞書の特徴

  • 辞書は、キーと値のペアを複数まとめて管理するデータ型です。
  • キーは重複してはいけません。
  • キーは変更できません。

辞書の例

person = {'name': '大久保', 'age': 40, 'gender': '女性'}
print(person)  # 辞書の中身を表示
#結果
{'name': '大久保', 'age': 40, 'gender': '女性'}

セットの基本

セットの定型

変数名 = {要素1, 要素2, ...}

セットの特徴

  • セットは、重複しない要素をまとめて管理するデータ型です。
  • セットは、集合演算を行うためのデータ型です。

セットの例

fruits = {'apple', 'banana', 'cherry'}
print(fruits)  # セットの中身を表示, 
{'cherry', 'apple', 'banana'}　#セットに順序という概念はない

セットの集合演算の例

set1 = {1, 2, 3, 4, 5}
set2 = {3, 4, 5, 6, 7}

print(set1 | set2)  # 和集合
#結果
{1, 2, 3, 4, 5, 6, 7}

print(set1 & set2)  # 積集合
#結果
{3, 4, 5}

print(set1 - set2)  # 差集合
#結果
{1, 2}

練習問題

問題 1

以下のデータ構造のうち、要素の追加や削除ができないものはどれですか？

タプルは一度作成すると、要素の追加、削除、変更ができない不変（イミュータブル）なデータ構造です。

問題 2

次の辞書型データの記述で、正しくないものはどれですか？

A) person = {'name': '大久保', 'age': 40}
B) scores = {1: 100, 2: 90, 2: 85}
C) info = {'id': 123, 'points': [80, 90, 85]}
D) data = {'x': 10, 'y': 20, 'z': 30}
辞書ではキーは重複できません。同じキーを使用した場合、後の値で上書きされます。

問題 3

セットの特徴として、正しくないものはどれですか？

セットは順序を持たないデータ構造です。要素の順序は保証されません。

問題 4

以下のタプルの操作のうち、実行可能なものはどれですか？

numbers = (1, 2, 3, 4, 5)

A) numbers[0] = 10
B) print(numbers[2])
C) numbers.append(6)
D) numbers.remove(3)
タプルは要素の変更はできませんが、インデックスを使用して要素にアクセス（参照）することは可能です。

問題 5

次のセットの演算結果として正しいものはどれですか？

A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

A | B の結果は？
和集合（|）は両方のセットのすべての要素を含み、重複は自動的に除去されます。
