外部ライブラリ【Matplotlib】

講義進度: 第11回

Matplotlib は、Python でグラフを描くときの「いちばん基本的な視覚化ライブラリ」です。折れ線グラフ・棒グラフ・散布図・円グラフなど、レポートや論文でよく見る図はだいたい Matplotlib だけで作ることができます。見た目の細かい調整（色、線の太さ、ラベルの位置など）がしやすく、「とりあえずグラフを描きたい」ときの標準ツールになっています。

Python には、ほかにもいくつか視覚化ライブラリがあります。たとえば Seaborn は Matplotlib をベースにしていて、統計グラフを少ないコードで見やすく描けるライブラリです。一方、Plotly などはマウスで値を確認できるような、インタラクティブなグラフや Web 上で動くダッシュボードの作成に向いています。

この授業では、まず Matplotlib を使って「グラフを描くための基本操作」を身につけます。そのうえで、必要に応じて Seaborn や Plotly のようなライブラリにステップアップしていけるよう、土台となる考え方や書き方を確認していきます。
