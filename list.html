リストの基本

リストの定型

変数名 = [要素0, 要素1, 要素2, ...]

リストの例

names = ['大久保','北沢','高橋','荒井','大谷']

リストの要素を取り出す

インデックス（要素の位置を表す番号）は0から数えます。Colabでは、コードセルの最後に式を書くと結果が表示されます。以下の取り出し例は、1行ずつ別のコードセルで実行してください。# 以降は、表示される結果を示すコメントです。

先頭から取り出す

names[0]  # 表示結果: '大久保'
names[1]  # 表示結果: '北沢'
names[2]  # 表示結果: '高橋'
names[3]  # 表示結果: '荒井'
names[4]  # 表示結果: '大谷'

末尾から取り出す

names[-1]  # 表示結果: '大谷'
names[-2]  # 表示結果: '荒井'
names[-3]  # 表示結果: '高橋'
names[-4]  # 表示結果: '北沢'
names[-5]  # 表示結果: '大久保'

範囲を指定して取り出す

names[0:3]  # 表示結果: ['大久保','北沢','高橋']（インデックス0から3未満まで）
names[2:4]  # 表示結果: ['高橋','荒井']（インデックス2から4未満まで）
names[3:]  # 表示結果: ['荒井','大谷']（インデックス3から最後まで）
names[:3]  # 表示結果: ['大久保','北沢','高橋']（最初から3未満まで）

リストの長さの取得

変数名 = len(リスト名)
names = ['大久保','北沢','高橋','荒井','大谷']
len(names)  # 表示結果: 5

メソッドを使って要素の追加・挿入・削除・反転・並べ替えをする

表の例は上から順に実行します。sort の例では、別のリスト scores を使用します。リストを変更する操作の後は、コードセルの最後に names と書いて変更後のリストを確認してください。pop() は削除した要素を返します。

メソッド 説明
リスト.append(x) 例:names.append('林')
リスト names の 末尾に '林' を追加する
変更後の names: ['大久保', '北沢', '高橋', '荒井', '大谷', '林']
リスト.insert(i, x)
インデックス i の位置に x を挿入する		 例:names.insert(2, '小林')
リスト names のインデックス2（先頭から3番目）の位置に '小林' を挿入する。変更後の names: ['大久保', '北沢', '小林', '高橋', '荒井', '大谷','林']
リスト.remove(x)
最初に見つかった、値が x の要素を削除する		 例:names.remove('小林')
リスト names の最初に見つかった '小林' を削除する。変更後の names: ['大久保', '北沢', '高橋', '荒井', '大谷','林']
リスト.pop()
リスト names の 末尾にある要素を削除する		 例:names.pop()
リスト names の 末尾にある要素を削除する
変更後の names: ['大久保', '北沢', '高橋', '荒井', '大谷']
リスト.index(x)
最初に見つかった、値が x の要素のインデックスを返す		 例:names.index('大久保')
最初に見つかった、値が 大久保 の要素のインデックスを返す
戻り値: 0
リスト.count(x)
要素に x が出現する回数を返す		 例:names.count('大久保')
リスト names の要素に '大久保' が出現する回数を返す
戻り値: 1
リスト.reverse()
要素の並びを反転する		 例:names.reverse()
リスト names の要素の並びを反転する
変更後の names: ['大谷', '荒井', '高橋', '北沢', '大久保']
リスト.clear()
全要素を削除する		 例:names.clear()
リスト names の 全要素を削除する
変更後の names: []
リスト.sort()
要素を小さい順に並べ替える		 例:scores = [72, 95, 60, 83, 68]
scores.sort()
コードセルの最後に scores と書いて確認する
変更後の scores: [60, 68, 72, 83, 95]
元のリスト自体が並べ替えられる。漢字の名前は、読みの五十音順に並ぶわけではない。

実習 5 リスト

Exercise-Python.ipynb のノートブックにつづけて以下の実習をしなさい。

操作ごとにコードセルを追加して、上から順に実行しましょう。変更後のリストを確認するときは、セルの最後に items と書きます。

  1. テキストセルを挿入し、# 実習5 リスト と入力しましょう。
  2. コードセルを挿入し、「ノート」「鉛筆」「消しゴム」「定規」「付箋」をこの順で要素とするリスト items を作成しましょう。
  3. 先頭の要素を items[0]、末尾の要素を items[-1] で取り出しましょう。それぞれ別のセルで結果を確認しましょう。
  4. items[0:3] で先頭から3つの要素を取り出し、別のセルで len(items) を実行して、元のリストの要素数を確認しましょう。
  5. append メソッドで「はさみ」を末尾に追加し、変更後のリストを確認しましょう。
  6. insert メソッドで「のり」を先頭から2番目に挿入し、変更後のリストを確認しましょう。
  7. remove メソッドで「消しゴム」を削除し、変更後のリストを確認しましょう。
  8. pop メソッドで末尾の要素を削除し、変更後のリストを確認しましょう。
  9. reverse メソッドで要素の並びを反転し、変更後のリストを確認しましょう。
  10. clear メソッドで items の全要素を削除し、空のリストになることを確認しましょう。
  11. 次の数値のリストを sort メソッドで小さい順に並べ替え、結果を確認しましょう。
