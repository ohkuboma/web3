関数の基本

関数の定型

def 関数名():
   関数内で実行する処理

関数の例　引数なし、戻り値なし

def say_hello():
    print('皆さん！こんにちは')
say_hello()
皆さん！こんにちは　# 実行結果
*引数なし、戻り値なしの場合の例
def say_hello2(name):
    print(f'{name}さん、こんにちは')
say_hello2('白山')
白山さん、こんにちは　# 実行結果
*引数あり、戻り値なしの場合の例

関数の例　引数あり、戻り値あり

def add(a, b):
    return a + b
print(add(1, 2))
3 # 実行結果

関数の例（引数あり、戻り値を変数に代入）

def calc_square(side):
    return side * side
result = calc_square(10)
print(result)
100 # 実行結果

関数の例（三角形の面積）

def calc_triangle(base=10, height=5):
    return base * height * 0.5
print(calc_triangle())
print(calc_triangle(base=20))
print(calc_triangle(height=10))

ここまでで、関数の基本を学びました。ここからは、これまでに学んだリスト、辞書、繰り返しを関数と組み合わせて、小テストを採点してみましょう。

同じGoogle Colabノートブックで、テキストセルとコードセルを一組ずつ、全部で三組作ります。各手順で、先にテキストセルに見出しと作業内容を書き、その下に新しいコードセルを作って実行しましょう。

小テストは3問です。各問の正解は一つで、正解するごとに1点です。

1. 一人分を採点する

テキストセル1に次の内容を入力しましょう。

# 応用問題　選択式の小テストを採点する

## 1. 一人分を採点する
採点する関数を作り、白山さんの回答を採点する。

テキストセル1の下にコードセル1を作ります。正解を第1問から順に並べると ['A', 'C', 'B'] です。白山さんの回答が ['A', 'B', 'B'] なら、第1問と第3問が合っているので2点です。Pythonでも同じ点数が出るか確かめましょう。

正解と回答のリストを関数に渡し、同じ位置の答えを一問ずつ比べます。一致したら1点を足し、全問を比べ終わったら合計点を返します。リストの位置は0から数えるので、i が0のときは第1問です。

def grade_quiz(answer_key, answers):
    score = 0
    for i in range(len(answer_key)):
        if answers[i] == answer_key[i]:
            score += 1
    return score

answer_key = ['A', 'C', 'B']
answers = ['A', 'B', 'B']
print(grade_quiz(answer_key, answers))
2 # 実行結果

2. 二人分を採点する

テキストセル2に次の内容を入力しましょう。

## 2. 二人分を採点する
白山さんと山本さんの回答をリストにまとめ、繰り返しの中で採点する関数を呼び出す。

表の1行が一人分のデータです。第1問から順に答えを並べると、例えば白山さんの回答は ['A', 'B', 'B'] になります。

名前と回答の対応
名前第1問第2問第3問
白山ABB
山本ACB
佐藤BCA

テキストセル2の下にコードセル2を作ります。一人分の名前と回答を辞書にまとめ、二人分を students というリストに入れます。for で一人ずつ取り出し、同じ関数にその人の回答を渡します。

students = [
    {'name': '白山', 'answers': ['A', 'B', 'B']},
    {'name': '山本', 'answers': ['A', 'C', 'B']},
]

for student in students:
    score = grade_quiz(answer_key, student['answers'])
    print(f"{student['name']}さん　{score}点")
白山さん　2点
山本さん　3点

関数の中の for は一問ずつ答えを比べ、関数の外の for は一人ずつ採点します。
