関数の基本

関数の定型

def 関数名():
   関数内で実行する処理

関数の例　引数なし、戻り値なし

def say_hello():
    print('皆さん！こんにちは')
say_hello()
皆さん！こんにちは　# 実行結果
*引数なし、戻り値なしの場合の例
def say_hello2(name):
    print(f'{name}さんこんにちは')
say_hello2('白山')
白山さん、こんにちは　# 実行結果
*引数あり、戻り値なしの場合の例

関数の例　引数あり、戻り値あり

def add(a, b):
    return a + b
add(1, 2) = 3

関数の例（引数あり、戻り値を変数に代入）

def calc_square(side):
    return side * side
result = calc_square(10)
print(result)
100 # 実行結果

関数の例（三角形の面積）

def calc_triangle(base = 10, height = 5):
    return base * height *0.5
calc_triangle()
25 # 実行結果
calc_triangle(base = 20)
50 # 実行結果
calc_triangle(height = 10)
25 # 実行結果
