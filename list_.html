リストの基本

リストの定型

変数名 = [要素0, 要素1, 要素2, ...]

リストの例

names = ['大久保','北沢','高橋','荒井','大谷']

リストの要素を取り出す

先頭から取り出す

names[0] = '大久保'
names[1] = '北沢'
names[2] = '高橋'
names[3] = '荒井'
names[4] = '大谷'

末尾から取り出す

names[-1] = '大谷'
names[-2] = '荒井'
names[-3] = '高橋'
names[-4] = '北沢'
names[-5] = '大久保'

範囲を指定して取り出す

names[0:3] = ['大久保','北沢','高橋']//要素0番目から3番目未満まで
names[2:4] = ['高橋','荒井']//要素2番目から4番目未満まで
names[3:] = ['荒井','大谷']//要素3番目から最後まで
names[:3] = ['大久保','北沢','高橋']//最初から3番目未満まで

繰り返し取り出す

for name in names:
    print(name)

     '''for 変数 in リスト名:
        繰り返し実行する処理'''
    
    
// 実行結果：
大久保
北沢
高橋
荒井
大谷

参考：要素と文を組み合わせる

print(f'私の名前は{name}です') 　// f-string を利用した表示
print('私の名前は' + name + 'です')　//一般的な文字列と変数の結合

メソッドを使って要素の追加, 挿入, 削除, 反転する

メソッド 説明
リスト.append(x) 例:names.append('林')
リスト names の 末尾に '林' を追加する
結果:['大久保', '北沢', '高橋', '荒井', '大谷', '林']
リスト.insert(i, x)
インデックス i の位置に x を挿入する		 例:names.insert(2, '小林')
リスト names の 2 番目の位置に '小林' を挿入する。結果:names = ['大久保', '北沢', '小林', '高橋', '荒井', '大谷','林']
リスト.remove(x)
最初に見つかった、値が x の要素を削除する		 例:names.remove('小林')
リスト names の最初に見つかった '小林' を削除する。結果:names = ['大久保', '北沢', '高橋', '荒井', '大谷','林']
リスト.pop()
リスト names の 末尾にある要素を削除する		 例:names.pop()
リスト names の 末尾にある要素を削除する
結果:names = ['大久保', '北沢', '高橋', '荒井', '大谷']
リスト.clear()
全要素を削除する		 例:names.clear()
リスト names の 全要素を削除する
結果:names = []
リスト.index(x)
最初に見つかった、値が x の要素のインデックスを返す		 例:names.index('大久保')
最初に見つかった、値が 大久保 の要素のインデックスを返す
結果:0
リスト.count(x)
要素に x が出現する回数を返す		 例:names.count('大久保')
リスト names の要素に '大久保' が出現する回数を返す
結果:1
リスト.reverse()
要素の並びを反転する		 例:names.reverse()
リスト names の要素の並びを反転する
結果:['大谷', '荒井', '高橋', '北沢', '大久保']

リストの長さの取得

変数名 = len(リスト名)
names = ['大久保','北沢','高橋','荒井','大谷']
len(names) = 5

配列の長さを利用して、リストの要素を表示する

names = ['大久保','北沢','高橋','荒井','大谷']
for i in range(len(names)):
   print(names[i])

  1. テキストセルを挿入し、markdown editor に# リスト　と入力

  3. append メソッドを利用して、（'別の名前’: 最初に入力した5名以外の名前）を追加し、names を表示して、変更後のnamesの要素を確認しましょう。
  4. insert メソッドを利用して、names の2番目の要素としてさらに’別の名前’を追加し、その後、namesを表示して の要素を確認しましょう。
  5. remove メソッドを利用して、names の最初に見つかった '荒井' を削除し、その後、names 表示して変更後の要素を確認しましょう。
  6. pop メソッドを利用して、names の末尾にある要素を削除し, その後、names を表示して、変更後のnamesの要素を確認しましょう。
  7. reverse メソッドを利用して、names の要素を反転し、names の要素を確認しましょう。
  8. sort メソッドを利用して、names の要素をソートし、変更後のnames の要素を確認しましょう。
  9. clear メソッドを利用して、names の全要素を削除したあと、変更後のnames の要素がどうなっているかを確認しましょう。
