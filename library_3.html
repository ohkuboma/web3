外部ライブラリ

講義進度: 第10回

ライブラリとは、Pythonでよく使う機能をまとめた「道具箱」のことです。あらかじめPythonに付属しているものを標準ライブラリ、自分でインストールして追加するものを外部ライブラリと呼びます。ライブラリを使うことで、数学計算やデータ分析、グラフ描画、Webとの通信などを、少ないコードで効率よく行うことができます。

ライブラリと近い仲間として、フレームワークと呼ばれるものもあります。フレームワークはアプリ全体の「骨組み」を用意してくれるもので、決められた型にそってプログラムを書いていきます。Pythonでは、Webアプリをつくるためのフレームワークとして Flask や Django がよく使われます。

さらに、プログラムを書いて動かすための開発環境（例：Jupyter Notebook や Google Colab など）もあります。開発環境は、コードを編集したり、実行結果やグラフを確認したり、メモを書きながら試行錯誤したいときに使います。

外部ライブラリのいろいろ

ライブラリ / フレームワーク 主な用途 説明
numpy 数値計算 多くの数値データをまとめて計算するためのライブラリ。統計や機械学習など、データ分析の土台として広く使われている。
pandas データ分析 Excelの表のようなデータを扱うためのライブラリ。読み込み・整形・集計など、実務的なデータ処理に向いている。
matplotlib グラフ描画 折れ線グラフや棒グラフなど、基本的なグラフを作成するためのライブラリ。分析結果を視覚的に伝えるときに使われる。
seaborn 統計グラフ描画 matplotlib をベースに、統計的なグラフを少ないコードで見やすく描画できるライブラリ。レポート用の図表作成にも便利。
openpyxl Excel操作 Excelファイル（.xlsx）の読み込み・編集・保存を行うライブラリ。PythonからExcelの自動処理を行いたいときに使われる。
requests HTTP通信 WebサイトやWeb APIとデータの送受信を行うためのライブラリ。外部サービスから情報を取得するときの基本ツール。
beautifulsoup4 HTML解析 WebページのHTMLを解析し、必要な情報だけを取り出すためのライブラリ。Webスクレイピングでよく利用される。
selenium ブラウザ自動操作 ブラウザを自動で操作するためのライブラリ。ログインが必要なサイトの取得や、画面操作の自動化に使われる。
scikit-learn 機械学習 分類・予測・クラスタリングなど、代表的な機械学習アルゴリズムをまとめたライブラリ。入門から実験レベルまで幅広く使われている。
Pillow 画像処理 画像の読み込み・トリミング・リサイズなど、基本的な画像処理を行うためのライブラリ。簡単な画像編集や前処理に利用される。
フレームワーク（Webアプリ／データアプリ向け）
Flask Webアプリ開発（軽量） 必要最低限の機能から始められるWebアプリ用フレームワーク。小規模なサービスやAPIを素早く試作したいときに向いている。
Django Webアプリ開発（本格派） ユーザー管理やデータベース連携など、Webサービスに必要な機能がひと通り揃ったフレームワーク。中〜大規模な開発で使われることが多い。
Streamlit データアプリ開発（手軽） Pythonのコードだけで、データの可視化や分析結果をWebアプリとして公開できるフレームワーク。プロトタイプやデモ用のアプリを素早く作成できる。
