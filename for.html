決まった回数だけ繰り返す

同じ処理を決まった回数だけ繰り返すには、for 文と range() を使います。

0から4までの数を表示する

for i in range(5):
    print(i)
# 実行結果：
0
1
2
3
4

range(5) は0から4までの整数を順に生成します。それぞれの数が変数 i に入り、字下げされた処理が合計5回実行されます。5は含まれません。繰り返す処理は、行の先頭を半角スペース4つ分字下げして書きましょう。

i + 1 で1から5までの数を表示する

for i in range(5):
    print(i + 1)
# 実行結果：
1
2
3
4
5

i は0から4まで変わります。表示するときに1を足すと、1から5までの数を表示できます。i + 1 を計算しても、変数 i 自体の値は変わりません。

1から5までの数を足し合わせる

total = 0

for i in range(5):
    total = total + (i + 1)

print(total)
# 実行結果：
15

繰り返しの前に、合計を入れる変数 total に0を代入します。total = total + (i + 1) は、今の合計に i + 1 を足し、その結果を total に代入する処理です。合計は1 → 3 → 6 → 10 → 15と変わります。最後の print(total) は字下げせず、繰り返しが終わってから合計を1回表示します。

+= を使って短く書く

total = 0

for i in range(5):
    total += i + 1

print(total)
# 実行結果：
15

数値の足し算と代入は、+= を使って短く書けます。ここでは total += i + 1 は total = total + (i + 1) と同じ意味です。

ここまでは数を表示したり足したりしました。次はリストの使い方を復習し、その後で、この数を添字として使ってリストの要素を順に取り出しましょう。

リストの復習

リストの定型

変数名 = [要素0, 要素1, 要素2, ...]

リストの例

names = ['大久保','北沢','高橋','荒井','大谷']

リストの要素を取り出す

先頭から取り出す

print(names[0])  # '大久保'
print(names[1])  # '北沢'
print(names[2])  # '高橋'
print(names[3])  # '荒井'
print(names[4])  # '大谷'

リストの長さの取得

変数名 = len(リスト名)
names = ['大久保','北沢','高橋','荒井','大谷']
print(len(names))  # 5

リストの要素を繰り返し取り出す（基本）

要素が5個のリストでは、len(names) が5になります。先ほどの range(5) と同じように、range(len(names)) から添字の0〜4を得られます。

配列の長さとカウンタ変数を利用して、リストの要素を表示する

names = ['大久保','北沢','高橋','荒井','大谷']

for i in range(len(names)):
   print(names[i])
# 実行結果：
	大久保
	北沢
	高橋
	荒井
	大谷

リスト（例：names） の要素を、変数（例：name） に順に受け渡して処理する

for name in names:
    print(name)
for 変数 in リスト名:
	繰り返し実行する処理
# 実行結果：
	大久保
	北沢
	高橋
	荒井
	大谷

参考：要素と文を組み合わせる

print(f'私の名前は{name}です')  # f-string を利用した表示
print('私の名前は' + name + 'です')  # 一般的な文字列と変数の結合

繰り返し取り出す　zip

# リストを定義する 
last_names = ['林','大谷','大久保','川島','川上']
first_names = ['亜夫','奈緒子','麻実','康博','孝之']
# 1行目：定義済みの last_names 配列と first_names 配列から、zip で対応する姓と名を一組ずつ取り出し、左から last_name・first_name として受け取る。 # 2行目：受け取った姓と名のあいだに半角スペース、名と「先生」のあいだにも半角スペースを入れて出力する。 

for last_name, first_name in zip(last_names, first_names):
  print(last_name + ' ' + first_name + ' 先生')

# 実行結果：
林 亜夫 先生
大谷 奈緒子 先生
大久保 麻実 先生
川島 康博 先生
川上 孝之 先生

繰り返し取り出す enumerate


# num は番号を受け取る変数名。enumerate() の番号は既定で0から始まる。
for num, last_name in enumerate(last_names):
    print("職員番号", num, "番目の" + last_name + " 先生")    


# 実行結果：
職員番号 0 番目の林 先生
職員番号 1 番目の大谷 先生
職員番号 2 番目の大久保 先生
職員番号 3 番目の川島 先生
職員番号 4 番目の川上 先生
