🐼 datetime 実習：試験まであと何日？

マリ風のやさしい解説と、トラ風コメントつきコード例です。

1️⃣ datetimeってなに？

時間や日付を扱うための箱みたいな道具。
Pythonの中では datetime モジュールにいろんな部品が入ってる。
日付だけなら date、時間込みなら datetime、差を表すなら timedelta。

2️⃣ 今日の日付を取り出す

from datetime import date
today = date.today()

今日がいつかを自動で教えてくれる。プログラムが「今」を知っているのがちょっと面白い。

3️⃣ 日付を自分で作る

exam = date(2026, 1, 15)

「年・月・日」を順に入れて日付を作る。Pythonでは月が1ずれることはありません。

4️⃣ 日付どうしを引き算する

diff = exam - today
print(diff.days)

差を取ると timedelta が返る。日付で算数ができるって新鮮。

5️⃣ timedeltaで日数を足したり引いたり

from datetime import timedelta
next_week = today + timedelta(days=7)

「一週間後」「三日前」など、日数でカレンダーを動かせる。

6️⃣ if文でメッセージを変える

日数に合わせて励ましの言葉を変えてみよう。

🎯 例題：試験まであと何日？（トラ風コメント入り）

from datetime import date

# 🐯 今日と試験日を設定だ。焦んなよ。
today = date.today()
exam_date = date(2026, 1, 15)   # ← 試験日をここに書いとけ

# 🐯 残り日数を出してみっか。
days_left = (exam_date - today).days

print(f"試験日：{exam_date}")
print(f"今日：{today}")

# 🐯 日数に合わせて、トラのぼやきが変わるぜ。
if days_left > 30:
    print(f"あと {days_left} 日。慌てんな、地道が一番の近道ってやつだ。")
elif days_left == 30:
    print("試験まであと1か月。焦る気持ちはわかるが、落ち着け。勝負はここからだ。")
elif 7 < days_left < 30:
    print(f"あと {days_left} 日。よし、得意分野で一発かましてやろうぜ。")
elif days_left == 7:
    print("試験まであと1週間！寝不足は敵だぞ。最後まで粘ってこい。")
elif 1 < days_left < 7:
    print(f"あと {days_left} 日。静かに仕上げる時期だ。焦りは捨てろ。")
elif days_left == 1:
    print("いよいよ明日だな。ここまでやったんなら、もう十分だ。自信持て。")
elif days_left == 0:
    print("試験当日だ！肩の力抜けよ、いつものお前でいけ。")
else:
    print(f"試験は {abs(days_left)} 日前に終わってる。おつかれさん。ちょっとは休め。")

このプログラムを実行すると、日付によってトラの励ましが変わります。
