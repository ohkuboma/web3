math モジュールのインポート

import math

import math は、mathモジュールを“使う準備”をするための合図です。

機能名 書き方 説明 戻り値の例

円周率 math.pi 円周率（π） 3.14159…

標準ライブラリ一の活用例（datetime）

datetime モジュールのインポート

from datetime import date,datetime,timedelta
datetime モジュールは 最初から Python に入っているので、インポートするだけで使えます。 from datetime import date, datetime, timedelta は、 datetime モジュールの中の機能（date・datetime・timedelta）を “使う準備” をするための合図です。

datetime モジュールで使える機能一覧

機能名 書き方 型（タイプ） 内容・説明 使う場面の例
今日の日付 date.today() datetime.date 今日の年月日だけを取得 学期の開始・終了日などに使う
今の日時 datetime.now() datetime.datetime 今日の年月日＋時刻を取得 時間まで正確に記録したいとき
時間の差 timedelta(days=7) datetime.timedelta 指定日数のずれを作る 1週間後、30日前などを計算
日付の引き算 日付2 - 日付1 timedelta 2つの日付の差を計算 誕生日まであと何日？など
日付の加算 日付 + timedelta(...) datetime.date 日付にズレを加えて未来を求める 提出日・試験日などの予測

pythonで日付に関する計算をする

from datetime import date, datetime, timedelta 
	      date（日付）, datetime（日時）, timedelta（時間の差）をインポート

today = date.today()                         # 今日の日付を取得（date型）
print(today)                                 # 出力例：2025-11-05

now = datetime.now()                         # 現在の日時を取得（datetime型）
print(now)                                   # 出力例：2025-11-05 23:06:30.123456

nextweek = today + timedelta(days=7)         # 7日分の「時間差」を today に加えるprint(nextweek)                              # 出力例：2025-11-12

pythonで日付の差分を計算する

from datetime import datetime

lastday = datetime(2026, 1, 22)
today = datetime.now()

left = lastday - today  # 日時の差（timedelta型）が計算される
print(left.days)        # .days で差分から「日数」だけを取り出して表示する
