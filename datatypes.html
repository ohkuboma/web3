データ型の種類と例

データ型の種類と例
型 型名（日本語表記） 値の例
int 整数型 -1, 0, 1, 2, 10, 100
float 浮動小数点数型 -0.12, 0.0, 0.5, 2.34
str 文字列型 'hello', 'こんにちは'
bool 真偽値型 True, False

実習 3 データ型

chapter1 のノートブックにつづけて以下の実習をしなさい

  1. テキストセルを挿入し、markdown editor に# データ型　と入力
  2. コードセルを挿入しint 型の変数を作成し、自分の年齢を代入しなさい。type()のかっこの中に変数を入れて実行して、その変数の型を確認しなさい。 
    age = 20  # 自分の年齢を入力
print(type(age))
  3. float 型の変数を作成し、自分の身長（小数点以下一桁まで入力。架空でもよし）を代入しなさい。type()のかっこの中に変数を入れて実行して、その変数の型を確認しなさい。
  4. str 型の変数を作成し、自分の名前を代入しなさい。type()のかっこの中に変数を入れて実行して、その変数の型を確認しなさい。
  5. bool 型の変数を作成し、（例：flg=True）type()のかっこの中に変数を入れて実行して、変数の型を確認しなさい。
